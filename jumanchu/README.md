# 07-pjt

### 프로젝트명 : 주만추(자연스러운 주식과의 만남 추구)
주제 : 자율주제(주식 투자)
철학 : 주식은 연애처럼 오래가야 한다.
서비스 개요 : 건강한 투자습관 정립을 도와주는 주린이들을 위한 주식투자 서비스 

---
### 1. 주요 기능
- API를 활용한 주식 종목 조회 기능
- 종목 및 포트폴리오 공유/리뷰 커뮤니티
- 재무제표 조회DART API 연동, 분기/연간 재무 데이터 분석
- 트렌딩 뉴스 기반 관련주 추천
- 매수/매도/관심 이유 기록 → 투자 성향 반영 종목 추천
- 투자 MBTI"당신은 ENFP형 투자자" 같은 결과, 투자 패턴 요약
- 장기투자를 위한 UI/UX 설계(연애같은 느낌의 UI/UX 설계)

### 2. 기술 스택
- Backend : DJango
- Frontent : Vue.js

### 3. 서비스 범위
- 한국 주식 시장(코스피, 코스닥) 전체
- 미국 주식 시장(나스닥 100)

### 4. 기본적인 사용자 흐름
- 회원가입, 로그인
- 온보딩(계좌 연동, 투자 성향 설정)
- 사용자의 생년과 동일한 상장년도를 가진 주식을 프로필로 설정(마케팅, 첫 거래 시 무료로 2만원 제공)
- 홈화면
    - 상단 : 시장 요약
    - 중단 : 내 포트폴리오 현황
    - 하단 : 커뮤니티 및 네비게이션 바
- 종목 추천(랜덥 & 트렌딩 뉴스 기반 & 기업 공시 기반 + 투자 성향 기반)
    - 트렌딩 뉴스 확인 -> 종목별 스크랩기능 제공
    - Tinder 스와이프 뷰(맘에 드는 종목 설정) 벤치마킹(직관성 극대화)
- 종목 구매, 판매 시 판단 보조 제공
- 구매, 판매, 관심 종목 관련 일기 작성 유도(어떤 근거 인지, 후회하는지)
    - 데이터화
    - 성향 개인화 및 투자 리포트 발행

### 5. 차별점
- 장기투자 실패 -> 연애/소개팅과 유사성을 발견 -> 취향을 담은 주식투자 서비스
- 판단 근거가 파편화되어있다는 점을 보완하기 위해 -> 종목별 뉴스 스크랩 폴더화
- 일기장 기능, 포트폴리오 커뮤니티 기능 -> 본인의 판단 근거를 가시화, 회고

### 6. 유의사항
- 실시간 연동 가능성 확인 필요
- 사용자 주문 처리 안정성 확보 필요
- 주식 추천 알고리즘 구현 가능성 확인 필요
- 보안 및 투자 관련 조언 관련 법적/윤리적 문제 주의
