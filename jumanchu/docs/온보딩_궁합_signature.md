# 온보딩 궁합 매칭 · 시그니처 · 4유형

> 온보딩 완료 1회 처리: 유저 5벡터 × Stock DNA → 궁합 점수 → 대표종목(signature) 박제 + 4유형 라벨.
> 구현: `backend/recommend/matching.py` (BE 임시 — 정율 Algo 분리 예정). 결정일 2026-06-17 · SCRUM-146.

---

## 1. 궁합 점수 (match_score, 0~100)

```
Total = risk×0.35 + term×0.20 + sector×0.20 + exp×0.15 + style×0.10  (×100)
```

| 요소 | 가중 | 산식 (유저 5벡터 ↔ 종목 DNA) |
|---|---|---|
| 리스크 | 35% | `1 − \|norm(risk_tolerance) − volatility\|` |
| 기간 | 20% | 단기(≤2)→변동 / 중기(3)→(안정+가치+변동)/3 / 장기(≥4)→(안정+가치)/2 |
| 섹터 | 20% | 관심섹터면 가중(1.0/0.6/0.3), 아니면 0.5 |
| 경험 | 15% | 초보(≤2)→안정 / 중급(3)→(안정+성장)/2 / 숙련(≥4)→(성장+변동)/2 |
| 스타일 | 10% | (가치+성장)/2 (추후 behavior 반영) |

- `norm(x) = (x−1)/4` 로 1~5 벡터를 0~1로 정규화. 각 요소 `[0,1]` 클램프.
- ⚠️ 문서 §2-5③의 `risk_tolerance/2.5`는 1~5를 0~2로 보내 음수가 나는 스케일 오류로 보여 `(x−1)/4`로 대체했다 — **정율 확인 필요**.

## 2. 시그니처(대표종목) 박제

- 후보 = **시장별(KR/US) market_cap 상위 200** (잡주·외국증권 배제). 전종목으로 하면 분위수 극단을 "아무도 안 사서 PBR·부채가 극단인 외국증권(차이나 종목)"이 차지해 신뢰도가 낮아짐.
- 후보 중 궁합 1등 → `investment_profile.signature_stock` 에 박제(가입 시 고정).
- 온보딩 응답에 종목·궁합점수·DNA 4축(레이더) 반환.

## 3. 4유형 (위험축 × 기간축)

- 위험축 = `(risk_tolerance + behavior)/2`, 기간축 = `investment_term`
- 위험축 ≥3 공격 / <3 안정, 기간축 ≥3 장기 / <3 단기

| | 장기 | 단기 |
|---|---|---|
| 공격 | 🌱 성장 동반형 | ⚡ 단기 승부형 |
| 안정 | 🌳 가치 파트너형 | 🔍 신중 탐색형 |

- 경험 배지: ≤2 🐣 입문 / =3 🐤 중급 / ≥4 🦅 숙련 → 예 `🦅 숙련 · 🌳 가치 파트너형`

## 4. 한계 / 후속

- KR+US 통합 후보라 한국 유저에게 미국 종목(예: REIT)이 시그니처가 될 수 있음. KR 우선 원하면 추후 가중/필터.
- 섹터는 20% 소프트 가중이라 관심섹터가 시그니처를 보장하진 않음.
- `recommendation_cache` 전종목 저장(스와이프 추천 리스트)은 별도.
- 5벡터 산출 정확도는 SCRUM-129 의존.
- 의존: Stock DNA 적재(SCRUM-145 · `docs/stock_dna_산정로직.md`).
