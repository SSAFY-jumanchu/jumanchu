## 2. 왜 이걸 하나 (배경)

- 주만추는 **"주식과의 궁합/만남"** 서비스다. 그런데 흔한 성향 분류(안정형/중립형/공격형)는 **어느 투자앱에나 있는 뻔한 라벨**이라 차별성이 약하다.
- 실제 **종목 이름**으로 유형을 주면:
  1. **컨셉 일치** — "궁합" 서비스인데 결과가 종목 궁합이라 딱 맞음
  2. **구체적·기억에 남음** — "공격형"보다 "엔비디아형"이 훨씬 와닿음
  3. **공유 욕구(바이럴)** — "나 삼성전자형 나왔어" 캡처해서 자랑하고 싶어짐
- 결정적으로 **이미 만든 궁합 계산을 재활용**하므로 **추가 개발이 거의 없다.**

## 3. 핵심 아이디어 — 하이브리드 (성향 유형 + 대표 종목)

추상적 성향과 구체적 종목을 **함께** 보여준다.

```
┌──────────────────────────────────────┐
│            🌳                          │
│        가치 파트너형                    │
│                                        │
│   당신과 가장 잘 맞는 주식은            │
│        삼성전자  💘 궁합 91점           │
│                                        │
│   ( 안정 · 대형 · 배당 선호 )           │
│                                        │
│        [ 주만추 시작하기 🎉 ]           │
└──────────────────────────────────────┘
```

- **성향 유형**(4유형 중 하나, 예: 가치 파트너형)이 "당신이 어떤 사람인지"를 설명
- **대표 종목**(삼성전자)이 그걸 구체적·기억에 남게
- → 추상(왜)과 구체(무엇)를 둘 다 잡는다

## 3-1. 성향 유형 정의 — 2축 4유형

성향 유형은 **위험 × 기간 2축으로 나눈 4유형**을 쓴다 (5벡터에서 계산).

**산식**
```
위험축 = (risk_tolerance + behavior) / 2     # 1~5  (loss_aversion은 risk에 녹아있음)
기간축 = investment_term                      # 1~5
경험   = experience                           # 1~5  → 레벨 배지
```

**경계**: 위험축·기간축 둘 다 **3 기준** (≥3 = 공격/장기, <3 = 안정/단기)

| | 🕐 단기 (기간<3) | 📅 장기 (기간≥3) |
|---|---|---|
| 🔥 공격 (위험≥3) | ⚡ **단기 승부형** | 🚀 **성장 동반형** |
| 🛡️ 안정 (위험<3) | 🔍 **신중 탐색형** | 🌳 **가치 파트너형** |

- 🚀 **성장 동반형** — 변동성 감수, 고성장주 장기 (엔비디아·SK하이닉스류)
- ⚡ **단기 승부형** — 모멘텀·테마 단기 (변동성 큰 종목)
- 🌳 **가치 파트너형** — 우량·저평가·배당 장기 (삼성전자류)
- 🔍 **신중 탐색형** — 보수적·짧게 관망 (안정 대형주)

**경험 레벨 배지**: `≤2 🌱입문 / 3 📊중급 / ≥4 🎓숙련` → 표시 예 "🎓 숙련 · 🌳 가치 파트너형"

**구현**
```python
위험 = (risk_tolerance + behavior) / 2
기간 = investment_term
TYPE = {
    (True,  True ): "성장 동반형",    # 공격·장기
    (True,  False): "단기 승부형",    # 공격·단기
    (False, True ): "가치 파트너형",  # 안정·장기
    (False, False): "신중 탐색형",    # 안정·단기
}[(위험 >= 3, 기간 >= 3)]
level = "입문" if experience <= 2 else ("중급" if experience == 3 else "숙련")
```

> ⚠️ 한계: 4유형엔 "중립"이 없어, 답을 다 균형(3점)으로 한 가운데 사람은 공격·장기로 쏠림. 데모 분포 보고 경계(3.5 등) 조정 가능. "중립" 완충대가 꼭 필요하면 3분류가 대안.

## 5. 동작 방식 (로직) — 새 알고리즘 없음

1. 온보딩 답 → **5벡터** 산출 (SCRUM-129 그대로)
2. 5벡터 × 전 종목 **Stock DNA** → **궁합 점수** (SCRUM-129 그대로)
3. **궁합 1등 종목 = 유형 이름** ("삼성전자형")
4. 성향 유형 라벨(가치 파트너형 등)도 5벡터에서 함께 산출

> 즉 **스와이프 추천에서 이미 계산하는 궁합 결과의 1등**을 라벨로 재활용하는 것. 새 알고리즘·새 테이블 불필요.

## 6. 데이터 / DB 영향 — 거의 없음

| 필요한 것 | 어디서 | 비고 |
|---|---|---|
| 궁합 1등 종목 | `recommendation_cache` (rec_type='onboarding', rank=1) | **이미 저장** |
| 궁합 점수 | 위 테이블 `match_score` | 이미 있음 |
| 성향 유형 라벨 | `investment_profile.investment_style` | 5벡터로 계산해 저장 (4유형) |
| 대표종목 박제 | `investment_profile.signature_stock_id` (신규 컬럼 1개) | **확정** — 가입 시점 궁합 1등을 고정 저장 |

→ **새 테이블 0개**, 신규 컬럼 1개(`signature_stock_id`).

## 7. 약점 & 보완책 (솔직하게)

| 약점 | 설명 | 보완 |
|---|---|---|
| **1등이 바뀜** | 종목 지표 갱신 시 어제 삼성전자형 → 오늘 SK하이닉스형 | ✅ **가입 시점 박제로 해결** (`signature_stock_id` 고정) |
| **다양성 부족** | 대형 우량주가 많은 사람의 1등이 되기 쉬움 → 다 "삼성전자형" | 일단 **1등 단독**, 데모에서 너무 똑같으면 상위3 중 개성 종목으로 보완(확장) |
| **의미 전달** | "삼성전자형"이 뭔 뜻인지 안 와닿을 수 있음 | 종목 특성 한 줄 병기 — "안정·대형·배당 선호" |

## 8. 결정 사항 (확정)

1. **대표 종목 = 가입 시점 박제** (실시간 갱신 X) → `investment_profile.signature_stock_id`에 저장
2. **다양성 보완 = 일단 안 함 (1등 단독)** — 데모에서 너무 똑같으면 그때 보완(확장)
3. **표현 = 하이브리드** (성향 4유형 + 대표 종목)
4. **성향 유형 = 2축 4유형** (§3-1)

## 9. 범위 / 우선순위

- **MVP (이번 데모)**: 하이브리드(성향 4유형 + 대표 종목) 결과 화면 + 마이페이지 유형 표시. 대표 종목은 **가입 시점 박제 · 1등 단독**. **궁합 결과 재활용**이라 BE 부담 작음, FE는 결과 화면 1개.

- **US-10(투자 MBTI, P2)와 통합** — 기획서의 "투자 MBTI" 자리를 이 종목형 유형이 대신할 수 있다. (별도 MBTI 알고리즘을 안 만들어도 됨)
