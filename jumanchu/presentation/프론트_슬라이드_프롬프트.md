# index.html 수정 프롬프트 — 프론트엔드 발표 슬라이드 추가 (2분 분량)

> **이 파일을 그대로 발표 준비자(또는 Claude)에게 전달**하면 됩니다.
> 대상 파일: `presentation/index.html` (reveal.js 데크)

---

## 작업 지시 (요약)

`presentation/index.html`에 **프론트엔드 엔지니어링 슬라이드 1장**을 추가해줘.

- **위치**: `<section id="sys">`(시스템 구조) 슬라이드 **바로 다음**, `<section id="done">`(구현 결과) **앞**.
- **분량**: 슬라이드 **1장**. 발표 시간 **2분**.
- **스타일**: 새 CSS 만들지 말고 **기존 클래스 재사용** — `section` / `kicker` / `h2` + `grad-text` / `lead` / `care-grid` + `care-card`(`cc-top`·`cc-num`·`cc-role`·`<h3>`·`cc-list`) / `why-foot`. (다른 슬라이드와 톤·여백 동일하게)
- **원칙**: 코드·숫자 디테일은 최소화. 청중은 비전공자 포함 — **"무엇이 문제였고, 어떻게 쉽게 풀었나"** 한눈에 들어오게.

---

## 슬라이드 내용 (이 두 기둥만 — 더 늘리지 말 것)

핵심 메시지: **"프론트는 화면만 그리는 게 아니라, 느린 원인을 구조로 줄이고(①) 남는 대기도 매끄럽게 감쌌다(②)."**

### 헤드라인(h2)
> 종목당 **100번** 부르던 걸, <span class="grad-text">한 번으로</span>.

### 카드 1 — 성능 (트러블슈팅)
- **제목: 100콜 → 1콜**
- 인기 종목 화면이 느렸던 진짜 원인은 **화면이 아니라 요청 구조** — 종목마다 가격을 따로 100번 호출(N+1)했다.
- 백엔드와 함께 **단일 API 1콜 + 미리 채워둔 캐시**로 통합 → **100콜 → 1콜.**
- (한 줄 교훈) *"느려요" 대신 "호출이 100개로 갈라져요"라고 말할 수 있게 된 게 협업의 핵심.*

### 카드 2 — 체감 속도 (UX)
- **제목: 기다리는 동안에도 화면이 살아있게**
- **빈 화면 깜빡임 제거** — 로딩 상태를 따로 보여줘 표가 번쩍였다 튀지 않게.
- **실패해도 안 죽게** — 에러 시 예시 데이터로 레이아웃 유지(캡션에 "예시" 표시).
- **즉시 반영 + 백그라운드 보강** — 관심 담기는 바로 추가하고, 시세는 뒤에서 채워 넣음.

### 푸터(why-foot)
> 체감 속도도 <span class="grad-text">속도</span>입니다 — 같은 응답 시간, 다른 인상.

## 발표 멘트 (약 2분, 그대로 읽어도 됨)

> "프론트엔드는 화면만 그리는 일이 아니었습니다. 가장 기억에 남는 건 **인기 종목 화면이 느렸던** 문제예요.
> 처음엔 제 렌더링 탓인 줄 알았는데, 백엔드 사수와 네트워크를 같이 들여다보니 진짜 원인은 **요청 구조**였습니다. 종목 100개를 띄우려고 **가격을 100번 따로 부르고** 있었고, 외부 시세 API는 동시 호출을 막고 있어서 더 느려졌죠.
> 그래서 백엔드와 협의해 **미리 채워둔 캐시에서 한 번에 내려주는 단일 API**로 바꿨습니다. **100번 호출이 1번**이 됐습니다.
> 그런데 1번으로 줄여도 네트워크는 0초가 아니거든요. 그 남는 대기 동안 화면이 비거나 깜빡이지 않게 신경 썼습니다. **로딩 상태를 따로 보여줘** 빈 표가 번쩍이지 않게 하고, **혹시 실패해도** 예시 데이터로 레이아웃을 유지했고, 관심 담기 같은 동작은 **먼저 화면에 반영하고 시세는 뒤에서 채워** 넣었습니다.
> 결국 배운 건, **체감 속도도 속도**라는 점, 그리고 *"느려요"가 아니라 "호출이 100개로 갈라져요"*라고 말할 수 있어야 백엔드와 제대로 협업할 수 있다는 점이었습니다."

## 넣지 말 것 (2분 초과 + 어려움 → 의도적으로 제외)

시간이 남을 때만 **한 줄로** 덧붙이되, 슬라이드 본문엔 넣지 말 것:

- 경합 토큰(오래된 응답 폐기, `popularLoadId`) — 개념이 어려움
- 동시성 제한(`mapLimit`, 동시 2건) 세부
- axios 인터셉터 401 refresh single-flight
- Pinia 영속 전략(메모리 vs 쿠키 vs localStorage) 표
- 시드 일봉 지연 보정 윈도우

> 이유: 2분 안에 청중이 **확실히 이해하고 임팩트가 큰** 두 가지(100콜→1콜 / 체감속도)에 집중. 나머지는 질문 받으면 답하는 용도.
