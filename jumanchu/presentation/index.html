  • 매수 사유 8종 · 매도 사유 6종 — 선택형으로 기록

  • 주문내역 자동 연동 — 일지 없는 주문은 작성 대기로
Algorithm ★ · Stock DNA

모든 종목에, 4축의 성격을 부여합니다.

예시 — 한 종목의 DNA 시그니처

2,649 종목 적재 한·미 시장별 정규화 일 1회 배치 캐시

완벽한 예측 모델이 아닙니다. 비교 가능한 기준입니다.
재무·시장 지표를 0~100 분위수로 환산해 종목의 성격을 정의합니다.

변동성 pct( β ) 시장 대비 출렁임 — 베타가 높을수록 ↑
가치 pct( 1 / PBR ) 저평가 정도 — PBR이 낮을수록 ↑
성장성 pct( 순이익 YoY ) 이익 성장 속도 — 값 없으면 중립 0.5
안정성 avg( 부채↓ · 유동↑ ) 재무 건전성 — 부채비율·유동비율 분위수 평균

핵심은 분위수(순위) 정규화 — 극단값에 면역, 한국·미국을 같은 잣대로 비교합니다.
