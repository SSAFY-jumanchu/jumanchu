## 7p — 궁합추천 (Core Feature 02 · Match) ★

### 한 줄 정의
사용자 **성향 5벡터** × 종목 **Stock DNA 4축**을 가중 매칭해 **0~100 궁합 점수**로 환산하고,
**근거(추천 사유)**와 함께 카드로 보여준다.

### 궁합 점수 = 5요소 가중합 (`compute_match_score`, matching.py)
각 요소를 0~1로 계산 → 가중합 ×100 = **0~100**.

| 요소 | 가중치 | 산식 (각 0~1) | 의미 |
|---|---|---|---|
| **리스크 (risk)** | **0.35** | `1 − |위험성향(1~5→0~1) − 변동성|` | 위험 성향과 종목 변동성의 **거리가 가까울수록** ↑ |
| **기간 (term)** | **0.20** | 단기(≤2)→`변동성` / 중기(3)→`(안정+가치+변동)/3` / 장기(≥4)→`(안정+가치)/2` | 보유 기간에 맞는 DNA 조합 |
| **섹터 (sector)** | **0.20** | 관심섹터면 가중치 `1.0 / 0.6 / 0.3`(1·2·3순위), 아니면 `0.5` | 관심 섹터 일치도 |
| **경험 (exp)** | **0.15** | 초보(≤2)→`안정` / 중급(3)→`(안정+성장)/2` / 숙련(≥4)→`(성장+변동)/2` | 경험 수준에 맞는 DNA 조합 |
| **스타일 (style)** | **0.10** | `(가치 + 성장)/2` | 종목의 가치·성장 성격 (추후 행동 데이터 반영 예정) |

> 가중합: `risk·0.35 + term·0.20 + sector·0.20 + exp·0.15 + style·0.10`, ×100 → 소수1자리 반올림.
> DNA 값이 null이면 중립 0.5로 대체. 위험성향 정규화는 `(x−1)/4`.

### 후보군 / 정렬
- **대형주만**: 시장(KRW·USD)별 `market_cap` **상위 200종목** → 잡주·소형 외국증권 배제. (`LARGE_CAP_TOP_N = 200`)
- 스와이프 추천: 이미 **관심 담은 종목 제외**, 궁합 점수 내림차순 상위 N(기본 30, 최대 50).
- **시그니처 종목**(가입 시 박제): 1순위 관심섹터 내 궁합 1등 우선, 없으면 전체 1등.

### 추천 사유 = **규칙 기반 한 줄** (LLM 아님, `_build_reason`)
형식: `🤝 {투자유형}{ · {섹터} 선호}에 {최고 DNA축}({값})이 잘 맞아요.`
예: `🤝 가치 파트너형 · IT서비스 선호에 성장성(78)이 잘 맞아요.`
- 최고 DNA축 = 4축 중 값이 가장 큰 축 (변동성/가치/성장성/안정성), 값은 ×100 반올림.

### 4유형 분류 (`classify_investor_type`)
- 위험축 = `(risk_tolerance + behavior)/2` ≥3 → **공격**, else **안정**
- 기간축 = `investment_term` ≥3 → **장기**, else **단기**

| | 장기 | 단기 |
|---|---|---|
| **공격** | 🌱 성장 동반형 | ⚡ 단기 승부형 |
| **안정** | 🌳 가치 파트너형 | 🔍 신중 탐색형 |

- 경험 배지: 🐣 입문(≤2) / 🐤 중급(3) / 🦅 숙련(≥4)

### 슬라이드 반영 포인트
- 좌측: "궁합 점수 = 5요소 가중합(0~100)" + 5요소·가중치 표.
- 후보 = 시총 상위 200 대형주, 담은 종목 제외, 사유는 **규칙 기반** 명시.
- 우측 카드 DNA 4축 = 변동성/가치/성장성/안정성, 사유는 `🤝 …` 형식.

## 8p — 장투케어 (Core Feature 03) + 장투 점수

### 장투 점수 산식 (`scoring.py`, `calc_longterm_scores.py`)
- **종목 소계** = 재무 `0.30` + 성장 `0.40` 가중평균 → `LongTermScore.total_score` (개인 무관, 일배치)
  - **재무 점수**(0~100, 5지표 평균): 부채비율(200%→0·0%→100), 유동비율(0→200%), 영업이익률(0→30%), 순이익률(0→25%), ROE(0→20%). 선형 환산, clamp 0~100.
  - **성장 점수**(0~100, 3지표 평균): 매출·영업이익·순이익 YoY → `0%=50점`, `±30%=0/100점`.
  - 한쪽만 있으면 그 점수만, 둘 다 없으면 데이터 없음(제외).
- **개인 장투 랭킹 최종**(`longterm_ranking`, on-demand) = `소계 × 0.70 + 개인 궁합(userfit) × 0.30`
  - 궁합 30%는 `compute_match_score`로 사용자별 즉석 계산. → **소계 70% + 궁합 30%** 가 핵심 메시지.
- 등급: A(≥90)/B+(≥80)/B(≥70)/C+(≥60)/C(≥50)/D.

### 매매일지 사유 (`diary/models.py` ReasonCategory) — 정확
- **매수 8종**: 장기 성장성 · 실적 개선 · 저평가 · 테마/모멘텀 · 뉴스 호재 · 기술적 반등 · 배당 매력 · 분산 목적
- **매도 6종**: 목표 달성 · 손절 · 차익 실현 · 펀더멘털 악화 · 더 좋은 기회 · 리밸런싱
- 함께 기록: 확신도(1~5), 목표가, 손절가, 메모. 주문(Order) 자동 연동.

### 슬라이드 반영 포인트
- "장투 점수 = 소계(재무30·성장40) 70% + 개인 궁합 30%" 명시.

## 9p — Stock DNA 알고리즘 ★ (`calc_stock_dna.py`) — 현재 슬라이드와 일치

### 4축 (시장별 분위수 정규화 0~1)
| 축 | 산식 | 비고 |
|---|---|---|
| 변동성 | `pct(β)` | 베타 높을수록 ↑ |
| 가치 | `pct(1/PBR)` | PBR 낮을수록 ↑ |
| 성장성 | `pct(순이익 YoY)` | 값 없으면 중립 0.5 |
| 안정성 | `avg(pct(부채↓), pct(유동↑))` | 둘 다 없으면 중립 0.5 |

> ⚠️ 슬라이드의 안정성 = `avg(부채↓·유동↑)` 가 **실제 배치와 정확히 일치**(모델 help_text의 `pct(1/beta)`는 구버전 주석, 배치가 진실).

### 핵심 설계
- **분위수(순위) 정규화**: 같은 시장(KR/US) 풀 내 백분위 → 극단값 면역, 한·미 동일 잣대 비교. 동점은 평균순위.
- **대상**: 활성 종목 중 `FinancialSummary` 보유 종목만 → **ETF/ETN/우선주/리츠 자동 제외**.
- **엣지 제외**: `β≤0`(인버스)·`PBR≤0`(자본잠식)·값 없음 → 계산 제외.
- 일 1회 배치 캐시(`StockDna`), 궁합 계산은 이 테이블만 읽음.

## 10p — 생성형 AI (정정 필요)

### ⚠️ 실제 생성형 AI(LLM) 사용처는 **장투 케어 리포트 단 1곳**
- 엔진: **GMS(SSAFY) 프록시 · GPT-4o** (`gms_client.py`, temperature 0.4, JSON 강제).
- 종목 1개당 **LLM 1콜**, 결과 캐시 TTL 1일.

### 장투 케어 리포트 = 4문장 (`longterm_report.py`)
보유/관심 종목 1개 → `financial · growth · userfit · final_opinion` 4개 문장 생성.
- 점수·등급·라벨은 **코드로 결정**(LLM 신뢰 안 함), 문장만 LLM.
- 라벨 밴드: ≥90 장기 핵심 보유 추천 / ≥80 장기 보유 추천 / ≥70 보유 유지·모니터링 / ≥60 비중 조절 검토 / else 보유 재검토.

### 환각 방지 가드레일 (프롬프트 명시)
- "제공된 **근거 수치만** 사용. 목표가·미래 전망·없는 지표를 지어내지 않는다."
- 데이터 없는 항목은 "데이터 없음"으로 정직하게 (`_NO_DATA`).
- 매수·매도 권유가 아닌, 이미 보유 종목 해설임을 명시.

### ⚠️ 정정: 추천 사유는 생성형 AI가 **아님**
- 궁합 추천 카드의 "🤝 …이 잘 맞아요"는 **규칙 기반 결정적 문자열**(`_build_reason`), LLM 미사용.
- → 발표 메시지: **"점수·추천·등급은 결정적 규칙으로 계산, 생성형 AI는 보유 종목 '해설'에만"**.
  (AI를 남용하지 않고 환각 위험을 구조적으로 차단했다는 강점으로 프레이밍.)

### 슬라이드 카드 구성(권장)
1. **장투 케어 리포트 (생성형)** — 보유 1종목 → 4문장, LLM 1콜, GMS·GPT-4o.
2. **환각 방지 설계** — 제공 수치만, 전망 금지, 없으면 '데이터 없음'.
3. **규칙은 결정적, AI는 해설만** — 궁합점수·추천사유·등급은 코드 계산, AI는 이해 보조.
