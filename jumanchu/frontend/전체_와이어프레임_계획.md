# 전체 와이어프레임 계획

> 주만추 프론트엔드 개선안. 기존 기획 문서 `사이트_UI_및_사용자흐름_정리jy.md`(이하 "기획안")가
> 정의한 **궁합 매칭 + 장투 케어** 서비스와, 현재 `frontend/src`에 구현된 화면을 비교해
> "무엇을 어떻게 바꿔야 하는가"를 화면 단위 와이어프레임으로 정리한다.

---

## 0. 이 문서를 쓴 이유 (핵심 진단)

기획안이 그리는 서비스의 정체성은 **"나와 궁합이 맞는 주식을 찾고, Like한 종목을 오래 보유하도록 케어하는 서비스"**다.
그런데 현재 구현은 **일반 주식 대시보드(시세 + 주문 미리보기 + 포트폴리오 + 커뮤니티)**에 스와이프 기능 하나를 얹은 형태에 가깝다.

| 항목 | 기획안이 요구하는 것 | 현재 구현 | 격차 |
|---|---|---|---|
| 서비스 정체성 | 궁합 점수 기반 매칭 + **장투 케어** | 시세/주문 중심 대시보드 + 스와이프 | 🔴 큼 |
| 온보딩 | 8문항 성향 설문 → 프로필 벡터 | 목표 이름/금액/성향 3스텝 | 🟡 보완 |
| 궁합 분석 로딩 | "당신과 맞는 주식을 찾는 중" 화면 | 없음 | 🔴 없음 |
| 추천 스와이프 | 궁합점수 + 한줄요약 + 이유3 + 지표 | 거의 구현됨(`SwipeCard`) | 🟢 좋음 |
| 종목 상세 | **궁합 요소별 분해**(리스크/기간/경험/테마/스타일) + Stock DNA + 뉴스 | 시세/차트/주문 미리보기 | 🔴 방향 다름 |
| 관심 종목 | 유지/주의/재고 **상태 배지** + 궁합 변화 + 재검증일 | 단순 가격 리스트 | 🟡 보완 |
| **장투 케어** | 월간 재검증 + 하락 심리지원 + 보유 마일스톤 | **라우트 자체가 없음** | 🔴 핵심 누락 |
| 마이페이지 | 성향 요약 + 선호 섹터 + 기록 | MBTI + 투자일기 | 🟡 방향 일부 다름 |

**결론:** 기능을 더 만드는 것보다, 이미 잘 만든 비주얼 자산(글래스모피즘 디자인 시스템, 스와이프 카드, 시장 패널)을 **기획안의 "궁합 + 장투 케어" 서사에 맞게 재배치**하는 것이 우선이다.

## 1. 현재 구현 현황 (있는 그대로)

### 라우트 (`src/router/index.js`)
```
/            HomeView        시장 지표 + 데이터 인벤토리 + 트렌딩 추천 미리보기

/community   CommunityView   게시글 피드 + 인기태그/인기글
/profile     ProfileView     유저카드 + 투자MBTI + 투자일기
/login /signup /onboarding   인증 3종
```

### 디자인 시스템 (`src/style.css`) — **이미 강점**
- 글래스모피즘 토큰 완비: `--glass-*`, `--radius`, 색상 토큰(`--accent`, `--positive`, `--negative`, `--purple`)
- 보라/블루/그린 그라데이션 배경, blur+saturate 유리 패널
- `.panel`, `.topbar`, `.eyebrow`, `.segmented`, `.field`, `.primary-action`, `.empty-state` 등 공통 클래스
- 좌측 고정 사이드바 레이아웃(`236px + 1fr`), 인증 페이지는 사이드바 숨김

> **재사용 원칙:** 새 화면도 이 토큰/공통 클래스를 그대로 써서 톤을 유지한다. 새 색·새 컴포넌트 스타일을 함부로 추가하지 않는다.

### 데이터 (`src/data/stocks.js`)
- 종목 6개 mock(코드/시세/`fit`(적합도)/`stance`/`reason`/`points`/`sparkline`)
- `inventory`, `marketBreakdown`, `sectorLeaders` mock

### 컴포넌트
- `SwipeCard.vue` — 드래그/버튼 스와이프, like/pass/save 이벤트, 적합도 표시 (**완성도 높음**)
- `StockWorkspace.vue` — 시세/차트/52주/Beta/변동성/ROE + 주문 미리보기
- `StockRow.vue`, `SparklineChart.vue`
- composable: `useWatchlist.js`(관심 토글), `useFormat.js`(통화/비율 포맷)

## 2. 개선 방향 3원칙

1. **서사 정렬** — 모든 화면을 "온보딩 → 궁합 분석 → 추천 → 관심 저장 → **장투 케어** → 마이" 흐름 위에 올린다.
2. **궁합 언어 통일** — 현재 흩어진 표현(`적합도`, `fit`, `트렌드 강도`)을 기획안 용어인 **"궁합 점수"**로 통일한다.
3. **누락 핵심 = 장투 케어 신설** — 기획안의 진짜 차별점인 월간 재검증/하락 심리지원/마일스톤을 새 라우트로 만든다.

### 제안 IA (정보 구조)
기획안 7장은 하단 탭 5개(홈/추천/관심종목/장투케어/마이)를 제안한다. 현재는 좌측 사이드바 6개 메뉴다.
**데스크탑 사이드바는 유지하되 메뉴를 기획안 5축으로 재정렬**하고, 종목/커뮤니티는 보조 메뉴로 둔다.

```
[ 제안 사이드바 ]
주만추
─────────────
홈            /
추천 (발견)    /discover
관심종목       /watchlist   ← StocksView의 관심 영역을 독립 화면으로
장투케어       /care        ← 신설 (핵심)
마이           /profile
─────────────
더보기
  종목 탐색    /stocks
  커뮤니티     /community
  포트폴리오   /portfolio
─────────────
[궁합 분석 상태칩]
```

## 3. 화면별 와이어프레임

> 표기: `[ ]`=버튼, `( )`=칩/배지, `▓`=차트/스파크라인, `→`=이동. 모두 기존 `.panel`/토큰 재사용 기준.

### 3.1 온보딩 (`/onboarding`) — 8문항으로 확장

현재 3스텝(목표 이름/금액/성향)을 기획안의 **성향 8문항 + 목표 설정**으로 확장. 진행률 바 유지.

```
┌──────────────────────────────────────┐
│  ●●●○○○○○  (진행률 3/8)               │
│                                        │
│         🎯  Q3. 손실 대응 방식         │
│   주가가 20% 떨어졌을 때 당신은?        │
│                                        │
│   [ 더 산다 (저가 매수) ]              │
│   [ 그대로 둔다 (장기 보유) ]   ← 선택 │
│   [ 일부 판다 ]                        │
│   [ 전부 판다 ]                        │
│                                        │
│   ← 이전              다음 →           │
└──────────────────────────────────────┘
```
- 질문 항목: 투자목적/기간/경험/리스크 이해도/손실 대응/투자 스타일/장단기/관심 산업(멀티칩)
- 답변 UI: 단일선택 버튼 · 슬라이더(리스크) · 멀티칩(관심 산업)
- 마지막 단계 후 → **궁합 분석 로딩**으로 이동(아래 3.2)
- 응답을 프로필 벡터로 직렬화해 `localStorage` 또는 `POST /auth/onboarding`(BE 합의 후)

### 3.2 궁합 분석 로딩 (`/matching`) — **신설**

```
┌──────────────────────────────────────┐
│                                        │
│            ◐ (회전 애니메이션)         │
│                                        │
│    당신과 잘 맞는 주식을 찾는 중…       │
│                                        │
│    ✓ 투자 성향 분석                    │
│    ✓ 종목 성격(Stock DNA) 매칭         │
│    ◐ 궁합 점수 계산 중…                │
│                                        │
└──────────────────────────────────────┘
```
- 3단계 체크리스트가 순차 점등(성향 분석 → 성격 매칭 → 궁합 계산)
- 1.5~2.5초 연출 후 자동으로 `/discover`로 이동 (기대감 부여용, 실제 계산은 즉시여도 OK)

### 3.3 추천 스와이프 (`/discover`) — 용어만 "궁합"으로 통일

`DiscoverView` + `SwipeCard`는 거의 완성. **변경은 라벨 위주(코드 수정 최소).**

```
┌─ 종목 발견 ───────────────[패턴 기반 | 뉴스 기반]┐
│ ┌─ 좌측 패널 ─┐   ┌──────── 스와이프 카드 ───────┐ │
│ │ 나의 궁합   │   │ (KOSPI · 전기전자)   궁합 91 │ │  ← "적합도"→"궁합"
│ │ 투자 목표   │   │  삼성전자  005930            │ │
│ │ [목표 위젯] │   │  현재가 317,000  +2.4%       │ │
│ │             │   │  "안정형에게 잘 맞는…"        │ │  ← 한줄요약
│ │ 관심 N개    │   │  매칭 포인트 3개 / ▓ 흐름     │ │
│ │ (칩 칩 칩)  │   │     [✕]   [♥]   [→]          │ │
│ └─────────────┘   └──────────────────────────────┘ │
└──────────────────────────────────────────────────┘
```
- `card.fit` 라벨 `적합도` → **`궁합`**, HomeView `트렌드 강도` → `궁합 점수`로 통일
- `[상세 보기]` 버튼/탭 추가 → 3.4 종목 상세(궁합 분해)로 진입

### 3.4 종목 상세 (`/stocks/:code`) — 궁합 분해 섹션 추가

현재 `StockWorkspace`(시세/차트/주문)는 유지하되, **상단에 "왜 추천됐는가" 궁합 분해 블록을 신설**.
주문 미리보기는 하단/탭으로 밀어 신뢰 설명을 먼저 보여준다.

```
┌─ 삼성전자 005930 ────────── 궁합 총점 91 ─┐
│  ┌─ 궁합 요소별 점수 ──────────────────┐  │
│  │ 리스크 궁합  ▓▓▓▓▓▓▓▓░░  88        │  │
│  │ 기간 궁합    ▓▓▓▓▓▓▓▓▓░  92        │  │
│  │ 경험 궁합    ▓▓▓▓▓▓▓░░░  74        │  │
│  │ 테마 궁합    ▓▓▓▓▓▓▓▓▓▓  95        │  │
│  │ 스타일 궁합  ▓▓▓▓▓▓▓▓░░  85        │  │
│  └────────────────────────────────────┘  │
│  Stock DNA: 안정 / 대형 / 배당             │
│  추천 이유 카드 ×3                         │
│  📰 뉴스 요약 (NewsData/Gnews 연동 예정)   │
│  [♥ 관심 종목에 저장]                      │
├───────────────────────────────────────────┤
│  [요약][차트][재무][주문]  ← 기존 탭 유지   │
└───────────────────────────────────────────┘
```
- `/stocks`의 인라인 선택 대신 `/stocks/:code` 라우트로 분리하면 추천 카드에서 딥링크 가능
- 궁합 요소 점수는 Algo 함수 반환값과 매핑(BE↔Algo 시그니처 합의 필요 → CLAUDE.md 인터페이스 규칙)

### 3.5 관심 종목 (`/watchlist`) — 상태 배지 도입

`StocksView`의 관심 영역을 독립 화면으로 승격. 핵심은 **유지/주의/재고 3단계 상태 배지**.

```
┌─ 관심 종목 ───────────────────────────────┐
│ ┌───────────────────────────────────────┐ │
│ │ 삼성전자        (🟢 유지)   궁합 91 ▲3 │ │
│ │ 최근 재검증 2026-05-01 · 하락알림 없음  │ │
│ │                              [상세 →]   │ │
│ ├───────────────────────────────────────┤ │
│ │ NVIDIA          (🟡 주의)   궁합 88 ▼2 │ │
│ │ 최근 재검증 2026-05-01 · -5% 알림 1건   │ │
│ ├───────────────────────────────────────┤ │
│ │ SK하이닉스      (🔴 재고)   궁합 71 ▼9 │ │
│ └───────────────────────────────────────┘ │
└────────────────────────────────────────────┘
```
- 카드 구성(기획안 5.1): 종목명 / 상태배지 / 현재 궁합 / 재검증일 / 하락알림 여부 / 상세 진입
- 배지 색은 기존 토큰 재사용: 🟢`--positive` 🟡`--warning` 🔴`--negative`

### 3.6 장투 케어 (`/care`) — **신설, 차별화 핵심**

기획안 5장 전체(월간 재검증 + 하락 심리지원 + 마일스톤)를 한 화면 3섹션으로.

```
┌─ 장투 케어 ───────────────────────────────┐
│ ① 이번 달 재검증                            │
│ ┌──────────────────────────────────────┐  │
│ │ 삼성전자          🟢 아직 좋은 파트너   │  │
│ │ ROE 8.6%↑ · 부채 92%✓ · EPS +12%✓ ·    │  │
│ │ PBR -8%(±30% 이내)✓                    │  │
│ └──────────────────────────────────────┘  │
│                                             │
│ ② 하락 심리 지원  (트리거 시 자동 노출)     │
│ ┌──────────────────────────────────────┐  │
│ │ ⚠ NVIDIA -5%   "단기 하락이에요.        │  │
│ │   펀더멘털은 그대로. 지금 팔기 아까워요" │  │
│ └──────────────────────────────────────┘  │
│                                             │
│ ③ 보유 마일스톤                             │
│ ( 🏅30일 ) ( 🏅90일 ) ( 🔒180일 ) (🔒1년) │
└─────────────────────────────────────────────┘
```
- ① 재검증 기준(기획안 5.2): ROE≥10% / 부채비율≤200% / EPS 증가율 + / PBR ±30%
  - 결과 3신호: 🟢 유지 / 🟡 주의 / 🔴 재고 (감성 문구 동반)
- ② 트리거: -5% 단기하락 / -15% 긴급 재검증 / 30·90일 경과 메시지
- ③ 마일스톤: 30/90/180/365일 배지 + 당시 지표 스냅샷 + 다음 마일스톤 안내
- 데이터는 초기엔 mock(`src/data/care.js` 신설) → 추후 Algo 재검증 함수 연동

### 3.7 마이페이지 (`/profile`) — 성향 요약 보강

현재 MBTI/투자일기는 유지하되, 기획안의 **투자 성향 요약 + 선호 섹터**를 상단에 추가.

```
┌─ 프로필 ───────────────────────────────────┐
│ [아바타] 송호영  (균형형 투자자)            │
│  일기 2 · 관심 3 · 매매 0                    │
│ ┌─ 나의 투자 성향 ─────────────────────┐   │
│ │ 균형형 · 12개월 · 중위험 선호           │   │  ← 온보딩 벡터 요약
│ │ 선호 섹터: (전기전자) (반도체) (운송)   │   │
│ └────────────────────────────────────────┘  │
│ [투자 MBTI 카드]  [투자 일기 리스트]         │  ← 기존 유지
└──────────────────────────────────────────────┘
```

### 3.8 홈 (`/`) — 진입 허브로 정리

현재 시장 지표 패널은 우수하니 유지. **상단에 "오늘 할 일" 행동 유도 스트립**을 추가해 케어로 연결.

```
┌─ 홈 ────────────────────────────────────────┐
│ 오늘 할 일:  ( 재검증 1건 ) ( 하락알림 1 ) ( 추천 12장 ) │
├──────────────────────────────────────────────┤
│ [시장 지표 패널 — 기존 유지]                  │
│ [오늘의 추천 미리보기 → /discover]            │
└──────────────────────────────────────────────┘
```

## 4. 우선순위 로드맵 (MVP 기준)

기획안 8장(Must/Should/Could)을 "기존 자산 재사용도"와 묶어 정렬.

### Must (먼저)
| # | 작업 | 신규/수정 | 비고 |
|---|---|---|---|
| 1 | 용어 통일 `적합도/fit/트렌드강도` → **궁합** | 수정(라벨) | 가장 싸고 효과 큼 |
| 2 | 궁합 분석 로딩 `/matching` 신설 | 신규 | 연출용, 가벼움 |
| 3 | 온보딩 8문항 확장 | 수정 | 프로필 벡터 직렬화 |
| 4 | 종목 상세 **궁합 분해 블록** | 수정 | `StockWorkspace` 상단 추가 |
| 5 | 관심종목 독립 화면 + 상태 배지 | 신규/이전 | `/watchlist` |

### Should (그다음)
| # | 작업 | 비고 |
|---|---|---|
| 6 | **장투 케어 `/care` 신설** | 차별화 핵심, 3섹션 |
| 7 | 하락 심리지원 카드 트리거 | mock 트리거부터 |
| 8 | 마이페이지 성향/선호섹터 요약 | 온보딩 벡터 연동 |

### Could (여유 시)
- 보유 마일스톤 배지 히스토리 / 업종 평균 비교 시각화 / 행동 기반 성향 재학습

## 5. 작업 시 주의 (CLAUDE.md 규칙 연동)

- **FE 코드는 송호영 담당** — 이 문서는 합의용 초안. 라우트/컴포넌트 신설 전 팀 공유.
- **궁합 점수·재검증 로직은 Algo(정율) 함수** → BE가 REST로 노출 → FE는 그 응답을 그린다.
  화면 만들기 전 **반환 타입 시그니처 합의 필수**(예: `{ total, risk, period, experience, theme, style }`).
- 우선은 `src/data/`에 mock(`care.js` 등)으로 화면을 완성하고, API 연결은 BE 준비 후 교체.
- 새 화면도 **기존 글래스 토큰·공통 클래스 재사용**. 색/컴포넌트 임의 추가 금지.
- 브랜치/커밋에 `[SCRUM-NN]` 포함, `dev` 대상 PR.
