## 📊 3. 온보딩 설문 → 유저 프로필 벡터

설문 결과는 단순 점수가 아닌 **투자 성향 벡터로 변환됨**

### 🎯 유저 프로필 구조

```python
user_profile = {
    "risk_tolerance":    1~5,   # 리스크 감수 성향
    "investment_term":   1~5,   # 투자 기간 (장기 성향)
    "experience":        1~5,   # 투자 경험
    "loss_aversion":     1~5,   # 손실 회피 성향
    "behavior":          1~5,   # 투자 스타일
    "preferred_sectors": []     # 관심 산업
}
📝 설문 핵심 로직
투자 목적 + 투자 기간 + 투자 방식 → investment_term
투자 경험 + 리스크 이해도 → experience
손실 대응 방식 → risk_tolerance
투자 스타일 → behavior
관심 테마 → preferred_sectors

👉 각 문항은 특정 벡터 값으로 직접 매핑됨

📈 4. 주식 성격 정의 (Stock DNA)

주식 데이터를 0~1 범위로 정규화하여 사용

stock_profile = {
    "volatility":   beta,         # 변동성
    "value_score":  0~1,          # 저평가 지표 (1/PBR)
    "growth_score": 0~1,          # 성장성 (EPS 기반)
    "stability":    0~1,          # 안정성 (1/β)
    "sector":       str
}
⚙️ 정규화 핵심 로직
변동성 → Beta 사용
가치 → PBR 역수 (1/PBR)
성장 → EPS 정규화
안정성 → Beta 역수
💘 5. 궁합 점수 알고리즘 (핵심)
📌 최종 공식
Total Score (0~100) =
    (risk_match   × 0.35)
  + (term_match   × 0.20)
  + (exp_match    × 0.15)
  + (sector_match × 0.20)
  + (style_match  × 0.10)
  × 100
🔍 6. 세부 궁합 요소
① 리스크 궁합 (35%)
ideal_beta = user["risk_tolerance"] / 2.5
risk_match = 1 - abs(ideal_beta - stock["volatility"])
유저 성향과 주식 변동성의 차이를 기반으로 계산
차이가 적을수록 높은 점수
② 투자 기간 궁합 (20%) ⭐ 핵심
if term >= 4:
    score = (stability + value_score) / 2
elif term == 3:
    score = (stability + value_score + volatility) / 3
else:
    score = volatility 기반
장기 투자자 → 안정성 + 저평가 선호
단기 투자자 → 변동성 선호
③ 경험 기반 궁합 (15%)
if exp <= 2:
    score = 안정성 중심
elif exp == 3:
    score = 균형
else:
    score = 성장성 + 변동성
초보 → 안정성
고수 → 성장성/변동성 허용
④ 테마 궁합 (20%)
if sector in preferred:
    1.0
elif no preference:
    0.5
else:
    0.0
관심 산업과 일치 시 높은 점수
⑤ 스타일 궁합 (10%)
score = (value_score + growth_score) / 2
가치 + 성장 균형 평가
추후 behavior 기반 가중치 적용 예정

## 💼 12. 장투 지원 기능 (Like 이후)

> **"추천에서 끝나지 않고, 장투를 끝까지 도와준다"**

Like한 종목 = 매수한 것으로 간주하고, 두 가지 방식으로 장투를 지원한다.

---

### 🔄 A. 월 1회 장투 재검증 — "아직 들고 있어도 돼?"

Like한 종목의 지표를 매달 다시 확인해서 **장투 유효성 신호**를 보여준다.

**재검증 기준 지표**

| 지표 | 기준 | 의미 |
|------|------|------|
| ROE | 10% 이상 유지 | 수익성이 살아있는지 |
| 부채비율 | 200% 이하 유지 | 재무가 버티는지 |
| EPS 증가율 | 전년 대비 플러스 | 실적이 성장하는지 |
| PBR | 처음 Like 시점 대비 ±30% 이내 | 여전히 저평가인지 |

**결과 신호 3단계**

| 신호 | 조건 | 메시지 |
|------|------|--------|
| 🟢 유지 | 4개 지표 모두 기준 충족 | "아직 좋은 파트너예요" |
| 🟡 주의 | 1~2개 지표 이상 | "지표 하나가 꺾였어요, 조금 지켜봐요" |
| 🔴 재고 | 3개 이상 이상 | "처음 추천 이유가 흔들리고 있어요" |

---

### 🧠 B. 하락 시 심리 지원 — "지금 떨어졌지만 괜찮아"

주가가 떨어지면 자동으로 장투 근거를 보여줘서 섣부른 매도를 막는다.

**트리거 조건**

| 상황 | 메시지 방향 |
|------|------------|
| 주가 -5% 이하 | "단기 하락, 펀더멘털은 이상 없어요" |
| 주가 -15% 이하 | 지표 긴급 재검증 결과 카드 표시 |
| 보유 30일 경과 | "한 달 버텼어요, 장투 점수 유지 중" |
| 보유 90일 경과 | "3개월 버텼어요, 궁합 점수 재계산 결과" |

**하락 시 노출되는 근거 카드 예시**

```
📉 삼성전자 오늘 -7%

하지만 장투 관점에선 이래요:
✅ ROE 15.2%  — 여전히 우량
✅ 부채비율 42% — 재무 탄탄
✅ 처음 담을 때보다 더 저평가 (PBR ↓)

💘 장투 궁합 점수: 79점 유지
"지금 팔기엔 아까운 타이밍이에요"
```

---

### ✨ C. 플러스 알파

**업종 평균 비교**
ROE, PBR을 절대값이 아닌 같은 업종 평균과 비교해서 보여준다.
→ "삼성전자 ROE 15% — 반도체 업종 평균(11%)보다 높아요"

**보유 기간 마일스톤**
30일 / 90일 / 180일 / 1년 시점마다 배지 + 그 시점 지표 스냅샷 저장.
→ 장투를 게임처럼 만들어 매도 충동을 줄이는 넛지.
