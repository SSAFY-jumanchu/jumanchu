# 재무 지표 컬럼 사전 (DART·KIS 가공 지표)

> `FINANCIAL_SUMMARY`, `STOCK_INDICATOR` 모델의 각 컬럼이 무엇을 의미하고, 어떻게 계산하고, 어디에 활용되는지 정리한 문서.
> 백엔드 구현 시·정율의 추천 알고리즘 입력 결정 시·FE 화면 라벨링 시 모두 참고.

## 사용법
- **컬럼명**: snake_case, 영문 (DB 컬럼명 그대로)
- **한국어 명**: UI에 표시할 라벨
- **계산식**: DART/KIS 원본 필드 또는 다른 지표 기반
- **단위**: %, 배수, 원, 일 등
- **우선순위**: P0 (Phase 2 필수) / P1 (시간되면) / P2 (학습 우선)
- **활용**: 추천·화면·필터링 어디에 쓰이는지

---

## 1. 원본 데이터 (DART / yfinance)

이 4개는 DART 또는 yfinance에서 그대로 가져오는 숫자. 가공 지표 계산의 입력.

| 컬럼명 | 한국어 명 | 단위 | 설명 |
|---|---|---|---|
| `revenue` | 매출액 | 원 | 분기 또는 연간 총 매출 |
| `operating_profit` | 영업이익 | 원 | 본업으로 번 이익 (매출 − 매출원가 − 판관비) |
| `net_profit` | 당기순이익 | 원 | 모든 비용·세금 제하고 최종 남은 이익 |
| `liabilities`, `total_assets`, `equity` | (참고) 부채/총자산/자본 | 원 | 가공 지표 계산용. DB에는 저장 안 함, 계산 후 폐기 |

> `liabilities` 등 원본 BS(재무상태표) 항목은 DB에 저장하지 않습니다. 가공해서 `debt_ratio` 등으로만 저장.

## 2. 수익성 지표 (Profitability)

"이 회사가 얼마나 효율적으로 이익을 만들어내는가"

### 🔴 `operating_margin` — 영업이익률  *P0*
- **계산식**: `operating_profit / revenue × 100`
- **단위**: %
- **의미**: 본업에서 얼마나 남기나
- **활용**: 종목 상세 — "본업 수익성 ⭐⭐⭐⭐☆", 추천 입력
- **참고치**: IT/제약 20% 이상, 유통/조선 5% 이하

### 🔴 `net_margin` — 순이익률  *P0*
- **계산식**: `net_profit / revenue × 100`
- **단위**: %
- **의미**: 모든 비용 제하고 최종 마진
- **활용**: 종목 상세, 비교

### 🟡 `roa` — 총자산순이익률  *P1*
- **계산식**: `net_profit / total_assets × 100`
- **단위**: %
- **의미**: 자산을 얼마나 효율적으로 굴리는가 (부채 의존도까지 반영)
- **활용**: ROE와 함께 보면 부채로 띄운 ROE 구별 가능

### 🔴 `roe` — 자기자본이익률  *P0* (STOCK_INDICATOR)
- **계산식**: `net_profit / equity × 100` (또는 KIS 제공)
- **단위**: %
- **의미**: 주주 돈을 얼마나 효율적으로 굴리나
- **활용**: 가치투자 핵심 지표 — "10% 이상이면 우량"

---

## 3. 성장성 지표 (Growth)

"이 회사가 얼마나 빨리 크고 있는가"

### 🔴 `revenue_yoy` — 매출 성장률 (전년 동기 대비)  *P0*
- **계산식**: `(당기 revenue − 전년 동기 revenue) / 전년 동기 revenue × 100`
- **단위**: %
- **의미**: YoY (Year over Year). 전년 같은 분기 대비
- **활용**: "성장주" 필터, 추천 입력
- **참고치**: 10% 이상이면 성장세, 마이너스면 역성장

### 🔴 `operating_profit_yoy` — 영업이익 성장률 (YoY)  *P0*
- **계산식**: `(당기 영업이익 − 전년 동기 영업이익) / 전년 동기 영업이익 × 100`
- **단위**: %
- **의미**: 매출만 늘고 이익은 안 늘면 의미 적음. 영업이익 성장률이 진짜.
- **활용**: 매출 성장과 함께 보면 "건강한 성장" 여부 판단

### 🔴 `net_profit_yoy` — 순이익 성장률 (YoY)  *P0*
- **계산식**: `(당기 순이익 − 전년 동기 순이익) / 전년 동기 순이익 × 100`
- **단위**: %

> **NULL 처리**: 전년 동기 데이터가 없거나 0이면 NULL. 신규 상장 또는 적자 → 흑자 전환 시 발생.

## 4. 안정성 지표 (Stability)

"이 회사가 망할 위험이 얼마나 되는가"

### 🔴 `debt_ratio` — 부채비율  *P0*
- **계산식**: `liabilities / equity × 100`
- **단위**: %
- **의미**: 자기 돈 대비 빌린 돈 비율
- **활용**: 안정성 평가, 위험성향 분류
- **참고치**: 100% 이하 안정, 200% 이상 부담, 400% 이상 위험

### 🟡 `equity_ratio` — 자기자본비율  *P1*
- **계산식**: `equity / total_assets × 100`
- **단위**: %
- **의미**: 총자산 중 내 돈 비율 (= 1 − 부채/자산)
- **활용**: debt_ratio와 보완적

### 🟡 `current_ratio` — 유동비율  *P1*
- **계산식**: `current_assets / current_liabilities × 100`
- **단위**: %
- **의미**: 1년 내 갚을 빚을 1년 내 현금화 가능한 자산으로 갚을 수 있나
- **활용**: 단기 지급 능력
- **참고치**: 150% 이상 안정, 100% 이하 주의

---

## 5. 가치 평가 지표 (Valuation) — STOCK_INDICATOR

"이 주식이 비싼가 싼가"

### 🔴 `per` — 주가수익비율  *P0*
- **계산식**: `current_price / eps`
- **단위**: 배 (배수)
- **의미**: "내가 낸 가격이 1년 순이익의 몇 배인가"
- **활용**: 저PER주 필터, 추천 입력
- **참고치**: 10~15배 평균, 5배 이하 저평가 또는 사양 산업, 30배 이상 성장 기대주

### 🔴 `pbr` — 주가순자산비율  *P0*
- **계산식**: `current_price / bps` (bps = equity / shares_outstanding)
- **단위**: 배
- **의미**: "내가 낸 가격이 회사 청산가치의 몇 배인가"
- **활용**: 1배 이하는 "장부가 미만 거래"

### 🔴 `eps` — 주당순이익  *P0*
- **계산식**: `net_profit / shares_outstanding`
- **단위**: 원
- **의미**: 한 주가 1년 동안 번 돈
- **활용**: PER 계산 입력

### 🔴 `dividend_yield` — 배당수익률  *P0*
- **계산식**: `annual_dividend / current_price × 100`
- **단위**: %
- **의미**: 주가 대비 연간 배당
- **활용**: "고배당주" 필터
- **참고치**: 3% 이상 고배당, 2% 이하 저배당

### 🟡 `payout_ratio` — 배당성향  *P1*  (FINANCIAL_SUMMARY)
- **계산식**: `total_dividend / net_profit × 100`
- **단위**: %
- **의미**: 순이익 중 배당으로 나간 비율
- **활용**: "주주환원" 종목 추천. 100% 초과면 빌려서 배당 = 비지속

## 6. 시장 변동성 지표 (Market-based) — STOCK_INDICATOR

"이 종목이 얼마나 들썩이는가"
> 일봉 데이터(`STOCK_PRICE`) 기반 자체 계산. 60일 이상 데이터 필요. 초기엔 NULL.

### 🟡 `beta` — 베타 (시장 대비 변동성)  *P1*
- **계산식**: `cov(stock_returns, market_returns) / var(market_returns)`
  - market: 한국=KOSPI, 미국=S&P500
- **단위**: 배수
- **의미**: 시장이 1% 오르내릴 때 이 종목은 몇 %? β=1이면 시장과 같음, β=1.5면 더 출렁, β<1이면 덜 출렁
- **활용**: **위험성향 분류 추천 입력** ⭐ (안정형=β<0.8, 공격형=β>1.5)
- **계산 주기**: 주 1회 또는 일 1회. 최근 60일 또는 90일 윈도우 권장

### 🟡 `volatility` — 변동성 (연환산 표준편차)  *P1*
- **계산식**: `stdev(daily_returns) × sqrt(252)` (252 = 연간 거래일 수)
- **단위**: %
- **의미**: 1년간 이 종목 가격이 평균적으로 ±몇 % 흔들리나
- **활용**: 위험 지표

### 🟡 `high_52w` / `low_52w` — 52주 최고/최저가  *P1*
- **계산식**: 최근 252거래일 최고/최저 close
- **단위**: 원
- **활용**: "신고가 돌파" 알림, "신저가 대비 +X%" 표시

## 7. 우선순위·구현 순서 요약

### Phase 2.2 종목 API 첫 PR — **P0 12개**
원본 3개 + 수익성 3개(operating_margin, net_margin, roe) + 성장성 3개 + 안정성 1개 + 가치 4개(per, pbr, eps, dividend_yield)

- 이자보상배율, 재고/매출채권 회전율 — 업종별 차이 커서 일반화 어려움. 발표 자료의 "확장 가능성"에만 언급.

## 8. 데이터 누락·이상치 처리

### 8.1 NULL 허용 케이스
- 신규 상장 (1년 미만): 모든 YoY 지표 NULL
- 적자 전환: net_margin·payout_ratio 음수 또는 NULL
- 무배당주: dividend_yield = 0, payout_ratio NULL
- 데이터 누적 부족 (60일 미만): beta, volatility, high/low_52w NULL

### 8.2 이상치 (값이 비현실적일 때)
- `debt_ratio > 1000%` 또는 음수: 잘못된 데이터 → NULL로 처리하고 로그
- `per < 0`: 적자 기업 → NULL (PER 의미 없음)
- `revenue_yoy > 500%`: 합병·인수 가능성 → 표시는 하되 "★ 합병/인수 가능성" 주석

### 8.3 API 실패 시
- DART 호출 실패: 이전 stale 데이터 그대로 반환 + 로그
- yfinance 실패: 동일

## 9. FE 화면 표시 가이드

- **소수점 처리**: 비율은 소수점 1자리 (`12.3%`), 배수는 2자리 (`12.34배`), 금액은 천 단위 콤마
- **음수 강조**: 빨간색
- **양수 강조**: 파란색 (한국 관습) 또는 녹색 (미국 관습) — 마켓별 분기
- **NULL 표시**: "—" 또는 "데이터 없음"

추천 트랙 1.2 "입력 변수 매핑"에서 정율이 선택할 수 있는 후보들:

| 추천 종류 | 주요 입력 후보 |

| 가치주 추천 | per (낮음), pbr (낮음), dividend_yield (높음), roe (높음) |
