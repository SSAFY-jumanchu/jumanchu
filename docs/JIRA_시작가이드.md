# 주만추 Jira 시작 가이드 (5분 컷)

> 처음 쓰는 사람을 위한 "어디 보고, 뭘 누르면 되는지" 가이드.

---

## 0. Jira에 들어가면 보이는 3개의 화면

왼쪽 사이드바에서 **"주만추_SSAFY"** 프로젝트를 선택하면 3가지 메뉴가 보입니다.

| 화면 | 언제 쓰나 |
|---|---|
| **보드 (Board)** | 매일. 내가 지금 하는 일을 본다 / 옮긴다 |
| **백로그 (Backlog)** | 주 1회. 다음 스프린트에 뭘 넣을지 정할 때 |
| **타임라인 (Timeline)** | 가끔. Epic 9개의 진행을 한눈에 볼 때 |

처음에는 **보드**만 매일 보면 됩니다.

---

## 1. 매일: "보드"에서 내 카드 옮기기

보드 → 4개의 컬럼이 보입니다.

```
┌─────────────┬─────────────┬─────────────┬─────────┐
│ 해야 할 일  │  진행 중    │  검토 중    │  완료   │
│  (To Do)    │ (In Progress│ (In Review) │ (Done)  │
│             │              │              │         │
│ SCRUM-1     │              │              │         │
│ SCRUM-3     │              │              │         │
└─────────────┴─────────────┴─────────────┴─────────┘
```

### 하루의 흐름

1. **아침** — 보드를 연다. 내가 시작할 카드를 **드래그해서 "진행 중"으로** 옮긴다.
2. **PR을 올렸을 때** — 그 카드를 **"검토 중"으로** 옮긴다. PR 링크는 카드 코멘트에 붙여두면 좋다.
3. **머지되고 동작 확인 끝** — **"완료"로** 옮긴다.

> 카드를 옮기는 건 그냥 마우스 드래그 한 번이면 됩니다.

---

## 2. 카드를 누르면 뭐가 나오나

카드를 클릭하면 오른쪽에서 상세 패널이 열립니다. 자주 쓰는 필드만 외우면 됩니다.

- **담당자(Assignee)** — 이 카드는 내가 한다고 적어두기. 보드에 내 얼굴 아이콘이 뜬다.
- **설명(Description)** — 무엇을, 왜 하는지. 인수 조건도 여기에.
- **댓글(Comment)** — 진행 중 발견한 이슈, PR 링크, 막힌 점을 기록.
- **라벨/우선순위/스토리포인트** — 이미 채워둔 항목. 새 이슈 만들 때 채우면 된다.

---

## 3. 새 일을 시작할 때: 이슈 만들기

보드 우측 상단의 **"+ 만들기"** 버튼 → 입력 항목 5개만 채우면 충분합니다.

| 항목 | 어떻게 채우나 |
|---|---|
| 이슈 유형 | 사용자 가치가 있으면 **스토리**, 없으면 **작업**, 결함이면 **버그** |
| 요약(제목) | 스토리면 사용자 관점 한 문장 / 작업이면 동사로 시작 |
| 상위 항목(Parent) | 해당하는 **Epic** 선택 (예: 회원가입이면 SCRUM-6) |
| 라벨 | `auth`, `stock-data` 등 가이드의 도메인 라벨 |
| 우선순위 | P1(High) / P2(Medium) / P3(Low) 중 하나 |

> 자세한 명명/입도 규칙은 `JIRA_관리구조.md` 1번 섹션에 정리돼 있습니다.

### 만들 위치 팁
- **이번 주에 할 일**이면 → "만들기" 후 보드의 "해야 할 일" 컬럼에 바로 뜸 (현재 스프린트에 자동 추가)
- **나중에 할 일**이면 → "백로그" 화면에서 만들기. 백로그 영역에 쌓임.

---

## 4. 주 1회 (월요일 아침): "백로그"에서 다음 스프린트 정하기

백로그 화면에 들어가면:

```
[ SCRUM Sprint 0 ]  ← 현재 진행 중인 스프린트
   SCRUM-1, SCRUM-3 ...

[ 백로그 ]  ← 아직 어느 스프린트에도 안 들어간 일들
   SCRUM-2 (회원가입 스토리)
   SCRUM-4 (sub-task)
   ... (앞으로 만들 일들)
```

### 다음 스프린트 시작하는 법

1. **"스프린트 만들기"** 클릭 → 새 스프린트가 만들어진다.
2. 백로그에 있는 이슈 카드를 **드래그**해서 새 스프린트로 옮긴다.
3. 옮길 때 **Story Point 합계**가 우측에 뜬다. 2-3인 팀이면 한 주에 **합계 8~15 정도**가 적당.
4. **"스프린트 시작"** 클릭 → 보드가 새 스프린트로 갈아낀다.

---

## 5. Epic은 어떻게 다루나

Epic은 보드에 카드로 안 뜹니다 — Epic은 "큰 묶음 이름표"라서.

대신:
- **백로그 화면 좌측** → Epic 패널을 펴면 Epic별로 자식 이슈를 필터링할 수 있다.
- **타임라인 화면** → Epic 9개가 막대 그래프로 보인다. 시작/종료 시점을 드래그로 조정 가능.

새 Story/작업을 만들 때 **상위 항목(Parent)에 Epic을 지정**하기만 하면 자동으로 그 Epic에 묶입니다.

---

## 6. 자주 막히는 지점

**Q. 보드에 내가 만든 이슈가 안 보여요.**  
→ 그 이슈가 현재 스프린트에 들어있지 않을 가능성. 백로그에서 찾아 현재 스프린트로 드래그.

**Q. 회원가입 sub-task(SCRUM-4)는 왜 보드에 따로 안 보이나요?**  
→ Subtask는 부모 카드(SCRUM-2) 안에 펼쳐서 보입니다. 부모 카드를 클릭하면 안에 sub-task 리스트가 있어요.

**Q. 스프린트 이름이 "SCRUM Sprint 0"인데 "Sprint 1"로 바꾸고 싶어요.**  
→ 백로그 화면에서 스프린트 옆 **⋯** 메뉴 → "스프린트 편집" → 이름 변경.

**Q. 일주일이 너무 길어요. 1주차 끝났는데 스프린트는 안 끝났어요.**  
→ 스프린트 종료일은 백로그 화면의 ⋯ 메뉴에서 편집 가능. 또는 일찍 끝내려면 "스프린트 종료"를 눌러 회고로 넘어간다.

**Q. 누가 무엇을 하고 있는지 보고 싶어요.**  
→ 보드 우측 상단의 **사람 아이콘**을 클릭하면 담당자별로 카드를 필터링할 수 있다.

---

## 7. 한 줄 요약 — "매일 이거만 하면 됨"

> 보드 열고 → 내 카드 드래그로 옮기고 → 새 일 생기면 "+ 만들기" 후 라벨/우선순위 채우기.

그 외는 나중에 익혀도 됩니다.
