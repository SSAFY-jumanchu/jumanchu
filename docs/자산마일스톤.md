# 자산 마일스톤 데이터 (Asset Milestones)

> 주만추(주식 추천) 서비스의 **"지금 이만큼 모았어요"** 기능용 데이터.
> 사용자의 현재 주식 자산 가치를 사람들이 체감하기 쉬운 실물 목표(자동차·집·기기 등)에 매핑해
> "당신의 주식 자산은 지금 OOO 한 대 값이에요" 식으로 보여주기 위한 기준 테이블입니다.

---

## 1. 설계 의도

- **하나의 오름차순 사다리**로 구성했습니다. 사용자의 자산 금액이 얼마든, 그 금액 바로 아래에서 "달성한 목표"와 바로 위의 "다음 목표(진행중)"를 찾을 수 있습니다. (첨부 UI의 _달성 완료 / 진행중_ 흐름과 동일)
- 수요가 높고 **금액이 직관적으로 와닿는 실물**(전자기기 → 명품 → 여행 → 자동차 → 부동산) 위주로 선정했습니다.
- 금액은 **2026년 6월 기준 한국 시세를 반영한 대표값(라운드 처리)** 입니다. 정확한 호가가 아니라 "체감용 기준점"이므로 운영 중 자유롭게 조정 가능합니다.

---

## 2. 권장 스키마

| 컬럼            | 타입     | 설명                                                                |
| --------------- | -------- | ------------------------------------------------------------------- |
| `id`            | int (PK) | 정렬·식별용. 작을수록 낮은 금액                                     |
| `name`          | varchar  | 목표명 (UI 노출 텍스트)                                             |
| `category`      | varchar  | `electronics` / `luxury` / `travel` / `car` / `realestate` / `life` |
| `tier`          | int      | 구간(1~5). 화면 그룹핑·필터용                                       |
| `target_amount` | bigint   | 목표 금액 (원, 정수)                                                |
| `icon`          | varchar  | 이모지/아이콘 키                                                    |
| `description`   | varchar  | 달성 시 보여줄 한 줄 멘트                                           |

> `target_amount`를 `bigint`로 두는 이유: 강남 아파트(26억)까지 들어가므로 `int`(최대 약 21억) 범위를 넘습니다.

## 5. 활용 로직 메모

사용자의 현재 자산 `assetValue`가 주어졌을 때, 첨부 UI(달성 완료 / 진행중 + 진행률 %)를 그대로 만들 수 있습니다.

```js
// milestones: 위 JSON (target_amount 오름차순 정렬 가정)
function getAssetProgress(assetValue, milestones) {
  // 이미 달성한 가장 높은 목표
  const achieved =
    [...milestones].filter((m) => assetValue >= m.target_amount).pop() ?? null;

  // 아직 못 넘은 가장 가까운 다음 목표
  const next = milestones.find((m) => assetValue < m.target_amount) ?? null;

  // 다음 목표까지의 진행률 (이전 목표 금액을 시작점으로)
  const base = achieved ? achieved.target_amount : 0;
  const percent = next
    ? Math.floor(((assetValue - base) / (next.target_amount - base)) * 100)
    : 100; // 최상위 목표까지 달성한 경우

  return { achieved, next, percent };
}
```

- **진행률 기준점**: 위 예시는 "직전 달성 목표 → 다음 목표" 구간 기준입니다. 첨부 UI의 *13% 달성*처럼 "0원 → 다음 목표" 절대 기준으로 보여주고 싶으면 `base = 0`으로 바꾸면 됩니다.
- **tier 활용**: 화면에서 "전자기기 구간 / 자동차 구간 / 부동산 구간"처럼 그룹 헤더를 보여줄 때 `tier`로 묶으세요.
- **추천 전략 연계**: 첨부 UI의 _공격형·반도체 우선_ 같은 멘트는 이 마일스톤과 별도 테이블(목표↔추천 포트폴리오)로 두고 `next.id`로 조인하는 구조를 권장합니다.

## 6. 금액 출처 · 주의

- 자동차: 2026년형 쏘나타 신차가 약 2,826~3,979만원, 아반떼(준중형)·캐스퍼/모닝(경차) 시세 기준.
- 부동산: 2025년 말 서울 아파트 평균 매매가가 약 15억 원을 돌파, 서울 중위(3분위) 약 12억대, 강남 3구 국민평형(전용 84㎡) 약 26억대 시세 반영.
- 스마트폰: 아이폰 17 Pro(256GB) 출고가 기준 약 170만원대.
- 위 금액은 **체감용 대표값**으로 라운드 처리했습니다. 실거래가는 지역·트림·시점에 따라 달라지므로, 운영 정책에 맞춰 주기적으로 갱신하는 것을 권장합니다.
