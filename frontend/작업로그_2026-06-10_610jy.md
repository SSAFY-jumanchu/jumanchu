## 수정 내역

### 1. `src/views/MyPageView.vue` — 마이페이지 3탭 재구성
와이어프레임 기준으로 정보구조(IA)를 **좌측 4-사이드바 → 상단 3탭**으로 변경.

| 구분 | 변경 전 | 변경 후 |
|---|---|---|
| 네비 형태 | 좌측 사이드바 4메뉴 | 상단 탭바 3개 |
| 탭 구성 | 내 정보 / 내 활동 내역 / 내 거래 내역 / 내 계좌 관리 | 내 투자 / 프로필 / 활동 내역 |

**탭별 구성 (와이어프레임 slide 9~11 기준)**
- **내 투자** (신설): 상단 3카드(기본계좌·주식 / 이달 수익 / 보유 종목 현황) → 수익분석 막대차트 → 내 거래 내역 테이블 + 요약 푸터
  - 기존 '내 거래 내역' + '내 계좌 관리'에 흩어져 있던 내용을 한 탭으로 통합
- **프로필**: 기본 정보 / 투자 성향 / 커뮤니티 프로필 (기존 '내 정보' 유지, 제목만 변경)
- **활동 내역**: 작성한 글 / 최근 활동 / 활동 통계

**제거 (와이어프레임에 없음)**
- 계좌 관리 리스트(거래내역 수신/우편/해외납세/수수료/계좌 탈퇴)
- 활동 내역 탭의 보유 배지 패널

**유지**
- 프로필 헤더 아이콘 🌱📈🔥 (사용자 요청으로 유지)

**헤더 버튼 동작**
- '프로필 편집' → 프로필 탭 + 편집모드 진입
- '내 계좌' → 내 투자 탭

**정리(리팩터)**
- 미사용 `badges` 6종 배열 → 헤더용 `headerBadges` 3개로 축소
- 인라인이던 `holdings` / `monthlyReturns`를 `<script>` 상수로 분리 (동작 동일)
- 실현 손익 합계: 양수·음수 분리 reduce → 전체 non-null 합산으로 단순화 (결과 동일)
- 안 쓰게 된 CSS 삭제: `.mp-sidebar`, `.mp-menu*`, `.badge-grid/item/icon/name/desc`, `.acc-manage-card`, `.manage-*`
