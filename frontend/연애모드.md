# 연애모드(장기연애 컨셉) 수정작업 명세서

> 작성: 정율 / 대상: `frontend/`
> 목적: **팀원(송호영)이 완성한 디폴트(노멀) 주식 서비스 코드 위에** 연애모드 토글을 그대로 다시 얹기 위한 머지 가이드.
> 핵심 원칙: **팀원의 화면 마크업·기본 문구·기본 톤은 그대로 둔다.** 연애모드는 토글 하나(`data-mode="dating"`)로 켜지고, 문구·비주얼만 덮어쓴다.

---

## 0. 동작 개요

- 네비 우상단 토글: 📈(기본) ↔ 💝(연애). `localStorage('jmc_mode')`에 저장, 새로고침 유지.
- 켜지면 `<html data-mode="dating">`이 붙는다.
  - **비주얼**: `style.dating.css`가 `[data-mode='dating']`에서 CSS 변수(`--accent` 등)만 로즈·코랄 웜톤으로 덮음 → 마크업 변경 0.
  - **문구**: 화면의 텍스트는 `t('키', '기본문구')`로 감싸져 있어, 기본 모드면 `기본문구`(팀원 것), 연애모드면 `copy/dating.js`의 연애 문구가 나옴.
- 기본 모드 동작/디자인은 전혀 바뀌지 않는다.

---

## 1. 새로 추가하는 파일 (그대로 복사 — 머지 충돌 없음)

팀원 코드와 겹치지 않는 신규 파일이라 **그냥 추가**하면 된다.

| 파일 | 역할 |
|---|---|
| `src/stores/mode.js` | 연애/기본 토글 상태 (theme.js 패턴 미러링) |
| `src/copy/dating.js` | **연애모드 문구 사전** (연애 텍스트는 전부 여기) |
| `src/composables/useCopy.js` | `t(key, fallback)` 헬퍼 |
| `src/style.dating.css` | `[data-mode='dating']` 비주얼 오버라이드 |

> 이 4개 파일은 현재 브랜치에 이미 있음. 팀원 브랜치에 없으면 그대로 가져오면 됨.

---

## 2. 기존 파일에 끼워넣는 변경 (팀원 완성본 위에 재적용)

아래는 팀원이 완성한 파일에 **추가/치환**해야 하는 지점. 팀원이 같은 파일을 새로 썼다면 이 스니펫만 다시 끼워넣으면 된다.

### 2-1. `index.html` — FOUC 방지 스크립트에 data-mode 추가

기존 테마 스크립트 끝부분에 2줄 추가:

```js
        document.documentElement.setAttribute('data-theme', theme)
        // ↓ 추가: 연애모드 — 저장값 없으면 normal(기본 주식 서비스)
        var mode = localStorage.getItem('jmc_mode') === 'dating' ? 'dating' : 'normal'
        document.documentElement.setAttribute('data-mode', mode)
```

### 2-2. `src/main.js` — 연애모드 CSS import

```js
import './style.css'
import './style.dating.css'   // ← 추가 (반드시 style.css 뒤에)
```

### 2-3. `src/components/AppNavbar.vue` — 토글 버튼

**(a) script — store import + 인스턴스**
```js
import { useModeStore } from '../stores/mode'   // ← 추가
// ...
const mode = useModeStore()                      // ← 추가
```

**(b) template — `.user-actions` 안, 테마 토글 바로 앞에 삽입**
```html
<button
  class="mode-toggle"
  type="button"
  role="switch"
  :aria-checked="mode.isDating"
  :aria-label="mode.isDating ? '기본 모드로 전환' : '연애 모드로 전환'"
  :title="mode.isDating ? '기본 모드로 전환' : '연애 모드로 전환'"
  @click="mode.toggle()"
>
  <span class="mode-toggle-track" :class="{ 'is-dating': mode.isDating }">
    <span class="mode-toggle-thumb">{{ mode.isDating ? '💝' : '📈' }}</span>
  </span>
</button>
```

**(c) style — `.theme-toggle` 규칙 아래에 `.mode-toggle` 스타일 추가** (현재 파일 참고; 테마 토글과 동일 패턴, 활성 트랙만 `rgba(236, 77, 126, 0.18)`).

**(d) 메뉴 라벨 — `navItems`에 `key` 부여 후 `t()`로 래핑**
```js
const navItems = [
  { to: '/', key: 'home', label: '홈' },
  { to: '/community', key: 'community', label: '커뮤니티' },
  { to: '/stocks', key: 'stocks', label: '주식 조회' },
  { to: '/holdings', key: 'holdings', label: '보유 종목' },
  { to: '/trading-diary', key: 'diary', label: '매매일기' },
  { to: '/portfolio', key: 'portfolio', label: '장투 케어' },
]
```
```html
{{ t('nav.' + item.key, item.label) }}  <!-- 기존 {{ item.label }} 대체 -->
```
연애 라벨: 커뮤니티→연애 상담소 / 주식 조회→인연 찾기 / 보유 종목→만나는 중 / 매매일기→데이트 기록 / 장투 케어→관계 점검 (홈은 그대로).

### 2-4. 화면 문구 래핑 — `t('키', '기본문구')`

각 화면에서 **기본문구(fallback)는 팀원 것 그대로 두고**, 텍스트를 `t()`로 감싸기만 하면 된다.
`<script setup>`에 공통 1줄:
```js
import { useCopy } from '../composables/useCopy'
const { t } = useCopy()
```

## 3. 새 문구를 연애모드로 바꾸는 방법 (앞으로의 패턴)

1. 화면에서 텍스트를 `t('적당한.키', '기존문구')`로 감싼다. (기존문구 = 기본 모드에 보일 값)
2. `src/copy/dating.js`에 `'적당한.키': '연애 버전 문구'` 추가.
3. 끝. 토글하면 자동 반영.

키가 사전에 없으면 fallback(기본문구)이 나오므로, **연애 문구를 안 넣은 텍스트는 자동으로 기본 모드와 동일**하게 동작한다.
